# Демо: возврат средств (Playerok)

Интерактивная демонстрация модального окна возврата по сценариям из Figma.

## Запуск

```bash
npm install
npm run dev
```

## Сценарии

1. Откройте начальное окно и укажите статус / балансы.
2. Нажмите «Показать форму возврата».
3. Форма динамически покажет доступные варианты возврата.

### Матрица

| Статус | Баланс продавца | Варианты |
| --- | --- | --- |
| В процессе | не используется | с баланса сделки / частичный |
| Завершена | ≥ баланса сделки | с баланса продавца / частичный |
| Завершена | > 0 и < баланса сделки | банк возвратов + частичные |
| Завершена | 0 | только банк возвратов |
